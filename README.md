# עזר נישואין מג"פ

"בנה לי מערכת CRM לניהול תורמים למגבית פורים בעברית מלאה (RTL). בסרגל הצד יהיו שני תפריטים: 'ניהול תורמים' ו'הגדרות'. במסך ניהול תורמים תהיה טבלה עם השדות: שם מלא, כתובת, טלפון, הערות, תרומה תשפ"ב, תרומה תשפ"ג, תרומה תשפ"ד, ותרומה לשנה הנוכחית. אני רוצה ששדות התרומה לשנה הנוכחית והערות לשנה הנוכחית יהיו ניתנים לעריכה ישירות בתוך הטבלה (Inline editing). במסך ההגדרות, תהיה אפשרות להגדיר את השנה העברית הנוכחית, וזה יעדכן את כותרת העמודה בטבלה. המערכת צריכה להיות פשוטה מאוד ומהירה לעבודה מהמחשב."
